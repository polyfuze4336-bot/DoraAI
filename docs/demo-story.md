# DORA Five-Minute Demo Story

Enable with `NEXT_PUBLIC_DORA_DEMO_STORY_ENABLED=true`. The global Demo Story controller remains inside the application shell and links only to real routes and APIs.

1. Open the command centre and observe the changed market posture.
2. Open Explain to see supporting/contradicting signals, measured model range, concise interpretation, source links and freshness.
3. Expand and open source evidence.
4. Run the actual scenario engine with material route disruption lasting 30 days; adjust sliders if needed and observe commodity/operational changes.
5. Preview the stored Monday HTML brief in `/reports` and demonstrate delivery's configuration-aware status.

Ask DORA remains available throughout for the question: “What happens if this disruption lasts another 30 days?” The scenario result and briefing are generated by application services, not screenshots or fake navigation pages.
