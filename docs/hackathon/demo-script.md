# DORA 5-Minute Demo Script

Target: 5 minutes, one browser tab, calm pace. Live app:
`https://dora-web.nicefield-0eb02a6f.eastus2.azurecontainerapps.io`

## Before You Start (2 minutes prep)

- Log in once beforehand so the session cookie is warm.
- Have the dashboard open and the weekly brief page reachable.
- Know your one commodity story (for example, a recent price move you can point at).

## Minute 0:00 — Framing (30s)

> "Commodity-exposed businesses drown in fragmented signals — prices, news, risk, operations. DORA continuously combines them so management can see what's happening, why it matters, and what could happen next. It's live on Azure right now."

## Minute 0:30 — Log in (20s)

- Show the login page, sign in with the prototype admin.
- Say: "Phase 1 uses simplified database-backed login; Microsoft Entra is configured for production."

## Minute 0:50 — Dashboard overview (60s)

- Point to the five intelligence domains: prices, news, risk, forecasts, manufacturing.
- "Everything numeric here comes from deterministic engines. This price and news data is **live** from World Bank and GDELT, refreshed by a scheduled Azure job."
- Flag manufacturing as demo: "Manufacturing is demo/synthetic to show the multi-domain view."

## Minute 1:50 — Forecast + explanation (70s)

- Open a commodity forecast. Show horizons (1/7/30/90) and the uncertainty band.
- "The projection is deterministic and reproducible. Now watch DORA explain *why*."
- Trigger the explanation / Ask DORA. "This narrative is generated by Microsoft Foundry, grounded in the retrieved evidence — never made up numbers."

## Minute 3:00 — Ask DORA (60s)

- Ask a natural question, for example: "What is driving the change this week?"
- Show the grounded answer with cited evidence.
- "The deterministic answer is the guaranteed baseline; AI adds the management language."

## Minute 4:00 — Weekly brief (40s)

- Open the weekly commodity intelligence brief.
- "This is the management deliverable — assembled from deterministic findings, written in Foundry, and deliverable by email through Azure Communication Services."

## Minute 4:40 — Close (20s)

> "That's DORA on Azure today: live ingestion, deterministic intelligence, grounded AI. Next, it evolves into enterprise data integration and a Microsoft Copilot Studio experience — without rebuilding this Azure backend."

## Fallback Plan

- If live ingestion is quiet, use already-persisted signals — they are real and were ingested by the scheduled job.
- If AI synthesis is slow, show the deterministic result and state that AI adds explanation on top.
- Never fabricate a number to fill a gap.
